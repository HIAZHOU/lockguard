# 锁车卫士 · LockGuard

Android 本地锁车确认助手：根据骑行、停车和步行信号，提醒你核实共享单车是否已锁好。支持 Android 8.0 及以上。

本项目是个人独立开发的非官方工具，与美团单车、哈啰、青桔等平台没有关联。它不能读取订单或车锁状态，也不能自动锁车；还车成功以平台确认为准。

## 下载与安装

安装包通过本仓库的 **Releases** 发布。打开仓库页面 → Releases → 对应版本 → Assets，下载以 `.apk` 结尾的附件。`Source code (zip)` 和 `Source code (tar.gz)` 是源码，不能直接安装。

**当前源码尚未配套发布经过本轮检查的正式签名安装包。** 如果 Releases 中没有 APK，表示该版本还未发布，请不要把本地旧调试包当作正式版。

下载后在 Android 手机上打开 APK，仅为下载所用的浏览器或文件管理器开启「允许安装此来源的应用」。安装后可关闭该开关。若系统报告签名冲突，不要反复安装；核对发布说明中的签名和升级说明。

## 使用边界

首次使用请按「更多 → 一键检查与设置」完成精确定位、通知和本机后台设置。后台省电策略、弱 GPS、慢骑或快走可能造成漏报或误报；不能依赖本应用判断是否停止计费。不要为了测试而故意保留真实未锁车订单。

应用自身未声明 `INTERNET` 权限，定位判断在本机完成；系统定位服务和你主动打开的其他应用适用各自的数据处理规则。诊断分享由你主动发起，发送前请阅读内容。
